## The 11 Functional Engines (Runtime Processors)

Engines transform Volume data into systemic output. Diagnose by failure signature;
fix with the matching protocol.

| Engine | Role | Failure signature | Systemic fix |
|---|---|---|---|
| 1. Perception (Sensorium) | Exact sense perception via the Markov blanket; manages sensory and active states | Observing what the model expects instead of what is | Deliberate observation loop; interview states, not narratives |
| 2. Feedback (Regulator) | Monitors stock discrepancies; spots balancing loops overwhelmed by reinforcing ones | Loop rigidity: a balancing loop becomes a reinforcing obsession | Introduce a disruptive information flow to break the loop's circularity |
| 3. Self-Organisation (Evolver) | Tension between evolution (Meadows) and identity (Maturana); new subsystems only if organization survives | Identity drift disguised as growth | Check: does the new structure preserve the core autopoietic organization? If organization changes, system identity terminates |
| 4. Boundary (Filter) | Constructs thick protective zones; filters linear-absolute noise | Boundary thinning; noise dictates internal state | Rebuild transition zones; input budgets; defended voids |
| 5. Inference | High-fidelity environment simulation; preemptive homeostasis | Surprise overload: the model can no longer predict reality | Execute Loop 1; update the generative model with exact sense perception; shrink prediction horizon |
| 6. Coupling | Coordinates the dance of reciprocal perturbations | System reacts to everything; world dictates internal structure | Restore mediation through the blanket; react without reorganizing |
| 7. Valuation | Assigns priority by the 15 properties; identifies flows that increase wholeness stocks | High-value stocks drained by low-value flows | Run the value hierarchy; re-rank flows by wholeness contribution |
| 8. Scale-Mapping | Matches intervention size to center size | Disproportionate fixes (grand or tiny) | Resize to half or double the center's scale (levels of scale) |
| 9. Repetition | Refines patterns through alternating repetition | Mechanical rigidity; same response everywhere | Vary each recurrence to local conditions |
| 10. Contrast | Sharpens system/other distinction | Semiotic blur; boundary ambiguity | Sharpen distinctions at the focal center |
| 11. Integration | Merges desires and beliefs into Middle Way equilibrium | Oscillation between dogmatic extremes | Apply agnosticism and provisionality; dampen the absolutisation loop |

## Failure Mode Quick Reference

1. **Loop Rigidity** (Feedback): balancing loop turned reinforcing obsession.
   Fix: disruptive information flow.
2. **Boundary Thinning** (Boundary): autopoietic distinction lost.
   Fix: reconstruct thick transition zones.
3. **Surprise Overload** (Inference): model cannot predict reality.
   Fix: Observation Loop (Loop 1) with exact sense perception.
4. **Oscillation** (Integration): swinging between dogmatic extremes.
   Fix: Middle Way agnosticism and provisionality.

## Engine Chaining

Loops 1 through 5 of the pipeline (see five-loop-pipeline.md) each lean on
specific engines: Loop 1 runs Perception + Inference; Loop 2 runs Valuation +
Scale-Mapping; Loop 3 runs Feedback; Loop 4 runs Repetition + Contrast + Coupling;
Loop 5 runs Integration. A failed engine shows up as a failed loop; diagnose
engines when a loop's marker line cannot be emitted honestly.
