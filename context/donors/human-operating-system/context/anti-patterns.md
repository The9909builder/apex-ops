## Failure Modes

1. **Pesticide Diagnostics**: prescribing a fix before naming the loop. Why it
   fails: Meadows' spruce budworm; the linear fix kills the balancing loop that
   was keeping the outbreak small, so the problem returns amplified. Corrected:
   `Leverage:` line first, loop type named, then match intervention level.

2. **Dashboard Absolutism**: treating a metric dashboard as the system. Why it
   fails: numbers are the weakest leverage point; dashboards show stocks but hide
   the flows and paradigms that generate them, so intervention lands at the wrong
   level. Corrected: ask what rule or paradigm the metric serves before adjusting
   the metric.

3. **Vibe Wholeness**: using "wholeness" and "centers" as inspirational language.
   Why it fails: Alexander's claim is structural and testable; field effects,
   thick boundaries, and voids are observable arrangements, and metaphor cannot
   be applied. Corrected: name the center, its boundary, and the observable field
   effect in one sentence before using the word.

4. **Blanket Bypass**: optimizing inputs without consulting the operator's states.
   Why it fails: the Markov blanket mediates everything; a model built from
   environmental noise alone (feeds, others' outputs) predicts the noise, not the
   system, and surprise compounds as anxiety. Corrected: interview states (energy,
   attention, drained hours) before designing any intervention.

5. **Efficiency Stacking**: adopting each new productivity system as it arrives.
   Why it fails: Burkeman's paradox; each gain is reabsorbed by new demands, so
   stacked systems compound load instead of reducing it. Corrected: every
   efficiency purchase must name the center whose stock it feeds and the slack it
   protects; unclaimed efficiency is not installed.

6. **Provisionality Theater**: saying "I hold this loosely" while acting on total
   conviction. Why it fails: Ellis' point is operational; a belief without a
   revision condition cannot update, so the system re-enters oscillation on the
   next collision with evidence. Corrected: the revision condition is written
   down, with the evidence that would trigger it, or the belief is dogma.

7. **Symmetry Enforcement**: sanding off every irregularity in pursuit of a clean
   system. Why it fails: roughness is functional; local irregularities carry the
   real constraints, and idealization deletes the information the next iteration
   needs. Corrected: preserve the irregular detail in the integration record and
   ask what constraint it encodes before removing it.

8. **Identity Blind Expansion**: adding new subsystems (habits, projects, tools)
   without checking the autopoietic organization. Why it fails: Maturana and
   Varela's bound; if the addition changes the organization rather than the
   structure, the system's identity terminates, which presents as quiet
   abandonment of everything. Corrected: check each addition against the core
   regeneration loop it must serve; no service, no adoption.
